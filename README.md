# Todo List Application

A console-based todo list application to help keep track of tasks.

## Features

- Add tasks
- Delete tasks
- Complete tasks
- Display tasks

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/daragonfly/todo-Girardot-CDOF2.git
   cd todo-Girardot-CDOF2
   ```

## Install Python (if not already installed)

1. Download and install Python for your platform from the [official Python website](https://www.python.org/downloads/).
2. Ensure Python 3.6 or later is installed by running:
   ```bash
   python --version
   ```
## Install Dependencies

No external dependencies are required. The application uses Python's standard library.

## Run the Application

Run the following command to start the application:
```bash
python code.py
```

## Usage Instructions

- **Add Task**: Select option `1` and type the task description when prompted.
- **Delete Task**: Select option `2`, then input the task number to delete.
- **Complete Task**: Select option `3`, then input the task number to mark as completed.
- **Display Tasks**: Select option `4` to view the list of tasks along with their status (Pending/Completed).
- **Exit**: Select option `5` to close the application.
